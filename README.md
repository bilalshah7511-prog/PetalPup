# Petal & Pup — Checkout Skin Demo

PayPhi-style checkout drawer skin for [Petal & Pup](https://petalandpup.com) (Outdoor Voices pattern).

## Font

**Sweet Sans Pro Regular only** (`public/fonts/SweetSansPro-Regular.ttf`). No other typefaces.

## Run

```bash
npm install
npm run dev
```
